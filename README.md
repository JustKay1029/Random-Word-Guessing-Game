**Random Word Guessing Game**

A tiny Python console game that chooses a random word and asks the player to guess it. This is a beginner project demonstrating loops, conditionals, and the `random` module.

**Quick Start**

- Prerequisites: Python 3.8 or newer.
- No external dependencies.

**Run locally**

1. Clone the repository:

```bash
git clone https://github.com/JustKay1029/Random-Word-Guessing-Game.git
cd Random-Word-Guessing-Game
```

2. Run the game:

```bash
python3 "Random word guess.py"
```

**Run in a notebook or online REPL**

- Open `Random word guess.py` in a Jupyter notebook cell or paste the code into an online Python REPL (e.g., Google Colab) and run the cell.

**Run in GitHub Codespaces**

- Click the green "Code" button, choose "Open with Codespaces", open a terminal, and run the `python3 "Random word guess.py"` command above.

**How to play**

- The program selects one of 10 words at random.
- Enter guesses when prompted until you find the correct word.
- The game uses a simple loop and conditional checks to compare your guess.
